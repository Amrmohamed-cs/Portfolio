Selected work

Three problems I worked through end-to-end

Fig. 01

Credit card fraud detection

Highly imbalanced binary classification — MLP + autoencoder ensemble

  • ·Removed duplicate transactions before the train/test split, so no duplicate pair could leak across sets.
  • ·Engineered an hour-of-day feature from elapsed time, and log-transformed the amount to tame extreme values.
  • ·Applied SMOTE to the training data only, to avoid inflating the test set with synthetic fraud cases.
  • ·Trained a deep MLP classifier and, separately, an autoencoder as an anomaly detector.
  • ·Combined both models' outputs through a logistic-regression meta-model (stacking).
  • ·Picked the decision threshold on the validation set by maximizing F2-score, weighting recall higher since missed fraud costs more than a false alarm.

Result on the held-out test set: 80.45% F1, 95.53% ROC-AUC.

Fig. 02

Loan status prediction

Approve/reject classification — compared four model families

  • ·Cleaned applicant financial and demographic data, and handled missing values and categorical encoding.
  • ·Split into train, validation, and a held-out test set kept untouched until the very end.
  • ·Trained and tuned four model families — logistic regression, decision tree, SVM, and random forest — each with GridSearchCV.
  • ·Compared them on validation F1 and ROC-AUC, and selected random forest as the final model.
  • ·Reported final performance only on the held-out test set, not the higher validation score, to be honest about generalization.
  • ·Reviewed feature importances to explain which applicant factors drove approval decisions.

Result on the held-out test set: 88.00% F1, 83.59% ROC-AUC.

Fig. 03

Hotel booking cancellation

Predicting no-shows from booking & guest features

  • ·Explored cancellation patterns by deposit type, room changes, family status, and lead time before modeling anything.
  • ·Ran chi² and ANOVA F-tests to select the features actually associated with cancellation.
  • ·Engineered features such as family status, company booking flag, and total stay length.
  • ·Trained a linear SVM baseline, then an RBF SVM tuned with RandomizedSearchCV, and a tuned KNN model.
  • ·Tuned the decision threshold for each model instead of defaulting to 0.5, to balance precision and recall.

Result on the test set (best model, RBF SVM): 67.74% F1, 81.13% accuracy.
